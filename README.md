# QuickBite – Online Food Delivery System

Restaurants list menus, customers order, riders deliver.

## Features

| Role | What they can do |
|---|---|
| Visitor | Browse restaurants & menus, live-search restaurants/dishes, register, log in |
| Customer | Place orders (multi-item), see own orders, cancel while *pending* |
| Rider | See *ready* unclaimed orders, claim one, mark own orders *delivered* |
| Admin | Full CRUD on **users, restaurants, menu items, orders** (status + rider assignment) |
